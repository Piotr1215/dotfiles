# CODEX

> Codex CLI shortcuts and account routing

- Open the Codex launcher in tmux:

`Alt + Shift + K`

- Open the Claude launcher in tmux:

`Alt + K`

- Start a Codex session:

`cx`

- Resume a session:

`cxr`

- Resume from every project:

`cxra`

- Fork a session:

`cxf`

- Synchronize the personal and work Codex homes:

`cxsync`

- Pick a Codex skill outside tmux:

`Alt + Shift + K`

- Show the active account home:

`echo "${CODEX_HOME:-$HOME/.codex}"`
