# nvim-telescope

> Telescope pickers in neovim. Config: ~/dev/dotfiles/.config/nvim/lua/telescope-setup.lua

- Find files in the tmux working directory (hidden, no .git):

`<leader>ff`

- Find files across ~/dev and ~/loft:

`<leader>fd`

- Git-tracked files in PWD:

`<leader>fg`

- Project files (mapped project):

`<leader>fp`

- Project files (current project):

`<leader>fP`

- Live grep at the git root:

`<leader>fl`

- Live grep across ~/dev and ~/loft:

`<leader>fL`

- Live grep / grep string in the git root:

`<leader>lg`

- Live grep / grep string in the tmux session folder:

`<leader>lt`

- Grep string under cursor in ~/dev:

`<leader>fs`

- Grep the visual selection in the current repo:

`<leader>fs (visual)`

- Find in the current buffer:

`<leader>/`

- Buffers:

`<leader>bu`

- Recently opened files:

`<leader>fo`

- File browser with hidden files:

`<leader>fi`

- Repo list under ~/dev:

`<leader>fr`

- Zoxide directory jump:

`<leader>fz`

- Jumplist:

`<leader>fj`

- Search history:

`<leader>fh`

- Registers:

`<leader>re`

- Replace the visual selection from a register:

`<leader>rg (visual)`

- LSP document symbols:

`<leader>ds`

- Git status:

`<leader>gs`

- Todo comments:

`<leader>ft`

- Emoji picker (normal mode):

`<leader>fe`

- Emoji picker (insert mode):

`Ctrl + e`

- Colorschemes:

`<leader>fc`

- Help tags:

`<leader>?`

- YAML path picker (yaml buffers):

`<leader>yt`
